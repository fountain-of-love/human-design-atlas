# Human Design Vault Proof Run

## Purpose

This is the first audit of the vault structure. It verifies whether the page contract, dictionary, source model, and initial notes work together before the collection expands into the full ontology.

## Initial scope

- five Type pages;
- one general basics page;
- one 13-element theory page;
- one personal case study;
- one dictionary interface;
- one source index.

## Audit questions

- Do the five Type notes have a consistent shape?
- Are Strategy, Signature, and Not-Self Theme described consistently?
- Are personal chart details isolated from theory?
- Can a reader move from the basics page to each Type note?
- Are system descriptions separated from contemplative interpretation?
- Are sources clearly attributed by role?
- Does the dictionary contain enough vocabulary for the current notes?
- Are the current links portable Markdown links?

## First findings

- The Type notes already share a useful one-page shape.
- The theory and personal case study are now separated.
- The basics page links to the canonical Type paths.
- The dictionary and source index establish the vocabulary and provenance layers.
- Frontmatter, dictionary links, and six core concept notes now establish the first reusable concept layer.

## Exit criteria

The proof run is ready to close when:

- all current links resolve;
- the Type notes have consistent metadata;
- the six core concepts—Type, Strategy, Authority, Signature, Not-Self Theme, and Design/Personality—have dedicated notes or an explicit decision to defer them;
- source scope is visible in the notes;
- the page contract has been tested on at least one non-Type concept.
