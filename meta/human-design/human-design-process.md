# Human Design Note-Creation Process

This process keeps the vault incremental, source-aware, and internally consistent.

## Process

1. Select a concept from the index or current milestone.
2. Read `meta/human-design/human-design-spec.md` and the relevant dictionary entries.
3. Identify the concept’s source scope.
4. Capture source terminology and claims before rewriting.
5. Write the overview in original language.
6. Fill structured fields and preserve unknowns explicitly.
7. Link to existing concepts and avoid repeating canonical definitions.
8. Separate system description, practitioner interpretation, and contemplative prompt.
9. Add sources and caution where claims could be mistaken for evidence.
10. Check metadata, headings, links, and terminology.
11. Add the note to the current proof run.
12. Review the proof run before generalizing the structure.

## Review checklist

- [ ] Correct entity type and filename.
- [ ] Frontmatter is present and meaningful.
- [ ] Overview is readable without specialist knowledge.
- [ ] Structured facts are distinguishable from interpretation.
- [ ] Repeated terms use dictionary language.
- [ ] Links resolve to existing or intentionally planned notes.
- [ ] Missing information is visible.
- [ ] Sources are attributed by scope.
- [ ] Health, genetic, or psychological claims are not overstated.
- [ ] The note adds value beyond duplicating another page.
