# Human Design Source Index

This index records source roles rather than treating all references as equivalent.

## Source categories

| Category | Role in the vault |
| --- | --- |
| Human Design system sources | Describe the system’s own mechanics and terminology. |
| Gene Keys sources | Describe Richard Rudd’s related contemplative synthesis. |
| Practitioner sources | Offer interpretations that may vary by teacher or school. |
| Historical or comparative sources | Explain the I Ching, astrology, chakra, Kabbalah, or related traditions. |
| Scientific commentary | Discuss evidence, psychology, genetics, or claims from outside the system. |
| Vault synthesis | Original organization and cautious explanatory framing created here. |

## Source notes

Sources should be added with a clear role. A source that explains what Human Design teaches is not automatically evidence that the teaching is scientifically true. The vault should preserve that distinction.
