# Human Design Atlas

This repository is a structured, source-aware knowledge vault for Human Design and related contemplative systems.

It is designed for three reading modes:

- **Orientation:** approachable explanations for people discovering the system.
- **Comparison:** predictable structures for comparing Types, Centers, Planets, Gates, Channels, and Profiles.
- **Graph exploration:** links between concepts, sources, interpretations, and real-world case studies.

Human Design is documented here as an esoteric and contemplative system. The vault does not present it as scientifically validated psychology, genetics, medicine, or destiny.

## Three-layer structure

- **`meta/vault/` — meta-vault:** reusable knowledge-engineering practices that could later move into a separate vault-engineering repository.
- **`meta/human-design/` — meta-Human Design:** Human Design-specific dictionaries, indexes, specifications, processes, source models, and audits.
- **Content layer:** the actual Human Design theory, concepts, types, planetary elements, and case studies.

## Working principles

- Prefer a small, clear note over premature ontology.
- Keep source tradition, practitioner interpretation, synthesis, and empirical evidence distinct.
- Preserve uncertainty instead of filling gaps with confident prose.
- Link to canonical concepts instead of duplicating definitions.
- Expand through audited proof runs.
