# Type

## Overview

Type is one of the first organizing concepts in Human Design. It groups charts into five energy-pattern categories: Generator, Manifesting Generator, Projector, Manifestor, and Reflector.

## Core mechanics

Within the system, Type is used to describe how a person’s aura and energy are said to engage with life. It is paired with **Strategy**, which proposes a way of reducing resistance.

## Contemplative interpretation

Type can be used as a question about rhythm and engagement rather than as a fixed identity: “What happens when I experiment with the strategy associated with this category?”

## Boundaries and uncertainty

Type is a system classification, not a scientifically established personality category.
